## 使用打乱工具

先自行准备有权使用的两份输出，使用相同样本编号：

```text
## 【S01】
第一条输出

## 【S02】
第二条输出
```

在仓库根目录运行，输入文件可放在仓库外：

```bash
python3 evals/random-run/build-blind.py --a /你的路径/a.md --b /你的路径/b.md --out-dir /你的路径/新输出目录 --seed 20261113
```

工具生成`blind-package.md`和`answer-key.json`。只把匿名材料交给判读者，保管答案；不要将含第三方或私人文本的生成文件提交到本仓库。

重复编号、A/B编号不匹配或空样本会直接报错，不再静默取交集。目标结果已存在时停止，避免覆盖证据。

相同输入与种子可重建打乱结果，不能重现模型生成或判读。旧版before分组与种子20261113吻合；after原始种子没有可核对记录，不能声称同一个脚本可还原两轮分组。
