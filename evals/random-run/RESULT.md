# 模型A/B评测记录

核对日期：2026-11-14。试验日期：2026-11-13。记录分为首次对照和调整规则后的复测，以下按评测轮次呈现，不使用仓库发布版本编号。

## 方法与现有证据

40段中文，8类各5段，来自24个不同URL、22个域名。采样由未读取Skill的模型执行；A加载Skill、B不加载。统一请求为“请改写下面这段中文，让它读起来更自然”。判读模型比较两份改写，不知道A/B分组，也没有原文。

两轮都用同一批样本；第二轮只重跑A，B沿用第一轮输出。模型执行者知道自己是否加载Skill，因此本记录称为模型A/B盲评，不称双盲。没有人类编辑评审，模型版本和采样参数未完整记录。

公开数据：[逐题偏好与统计](results.json)。原文、改写副本及完整判读未公开，不能仅凭公开数据完整重现原试验。

## 执行偏差与局限

- 原协议要求排除不适合的样本后不替换；实际采集报告提到为每类取满发生补采。这是协议偏差，不能把这批材料称为严格随机样本。
- 多条来自同一个页面；24个URL也不等于24个独立作者。
- 判读模型只有一个，部分记录改用“更像原文”的表述，与“自然”并不完全同义；主观尺度有波动。
- 判读者未见原文，不能单独判断保真，保真另由主执行者核对。
- 两轮B输出固定，并非两轮重新生成的完整对照。文本、模型时点与执行上下文的影响没有被充分控制。
- before的分组可用记录的种子20261113重建；after现有答案不匹配该种子，原始种子未找到。
- 原文及完整输出未公开，公开证据不支持完全复现；将来可换用允许再分发的样本重新试验。
- 当前版本还包含两轮之后的规则修改，未在本轮结果中验证。不把旧成绩转用于当前版本宣传。

## 可以保留的问题发现

历史记录暴露了信息被删、体裁被抹平、添加未给细节、明显笔误漏改及格式破坏等问题。它们可以指导回归检查，但不足以证明修改后的规则普遍有效。
